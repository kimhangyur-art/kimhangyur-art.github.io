# A-08 이미지코드 체계와 마르타 코드

> - **한 줄 요약**: 여캐 이미지코드가 G+한 글자(26자리)라 업데이트 몇 번이면 바닥나는 문제를 네 체계(H 접두 / 단역 공용 코드 / 분류 접두 / 숫자)로 비교하고, 지금 남은 자리(GQ~GZ)의 배정 시뮬레이션과 마르타 GQ를 정리했다. 추천은 'G 26자리 → H 접두'에 '단역 공용 코드'를 더한 조합.
> - **기댄 확정 설정**: 수정본4 본문 「이미지출력」(양식 `![](https://gobl.uk/[작품폴더]/이미지코드/상황코드.webp)`, 남성 인물은 1~25만, 코드 없는 인물(-)은 생략, 코드가 여럿인 인물 규칙, 이미지코드를 이름 대신 쓰지 말 것) / 일지(11-26) "메데이아 이미지 코드는 GK/GKA/GKB/GKC로 구분. 네르구이는 GLA/GLB로. 에이다 스미스 GM. 알리타 GN… 미라 GO 메르헨 GP. 흠. 이런 식으로 하니까 여캐 26인 넘으면 곤란해지겠는데. 고민해 보자." / 일지 "일반 몬스터도 에셋 한 두 장 정도는 쥐어 주자. 공용 에셋 돌려쓰면 좋을 듯. 필요한 에셋은 맹수, 맷돼지, 오크, 트롤, 드래곤." / 수정본4 메모 [대기18]·[대기19]·[제안3]·[출시]2·3
> - **새로 제안하는 것**: 체계 네 안 비교, GQ~GZ 배정표, 단역·몬스터 공용 코드 규칙 문안(글자 수), 남성 코드 확장
> - **바꾸거나 정하는 미확정 항목**: [대기18] 이미지코드 26 한계 이후 / [대기19] 마르타 코드 / [제안3] 다중 코드 배정(GKA=골렘 순서)은 그대로 둠

## 3. 26자리 이후 — 체계 네 안

### 안 ① H 접두 (GA~GZ 다음 HA~HZ)

- 여성 기본 코드를 G로 다 쓰면 H로 넘어간다. HA, HB…
- **장점**: 규칙이 단순하다. 지금 코드를 하나도 바꾸지 않는다. 폼 접미(GKA)와 겹치지 않는다(두 글자 기본 + 세 글자 폼 규칙 유지).
- **단점**: H가 '두 번째 묶음'이라는 것 말고 뜻이 없다. 남성 코드 M 계열과 헷갈릴 일은 없다.
- 본문 변경: 없음(새 코드는 표에 쓰면 됨).

### 안 ② 단역 공용 코드 (GMOB / MMOB — 수정본4 [대기18]이 적은 작가 전작 방식)

- 이름 없는 단역 여성/남성이 **하나의 코드를 공유**한다. 여관 손님, 마을 처녀, 행상 등 누가 나와도 같은 이미지 묶음.
- **장점**: 단역에 코드를 하나씩 쓰지 않으니 기본 자리가 줄지 않는다. 엑스트라 칸([대기9])을 늘려도 코드 부담이 없다. 일지의 "공용 에셋 돌려쓰면 좋을 듯"(몬스터 대목)과 같은 생각이다.
- **단점**: 서로 다른 단역이 같은 얼굴로 나온다. 한 장면에 단역 둘이 나오면 이미지가 겹친다. 이미지와 텍스트의 괴리가 '치명적이지 않은 수준'이면 괜찮다(일지: 단순한 인물은 "이미지와의 괴리가 치명적이지 않을 수준으로만 고정").
- 본문 문안(「이미지출력」 '코드가 여럿인 인물' 줄 뒤에) — 33자(메인 +34자)
```
- 이름 없는 단역: 여성 GMOB / 남성 MMOB 공용.
```

### 안 ③ 분류 접두

- 주연 여성 G, 남성 M, 단역 여성 N, 몬스터 Z 식으로 첫 글자를 분류에 쓴다.
- **장점**: 코드만 보고 분류를 안다. 몬스터 공용 에셋(일지의 맹수·멧돼지·오크·트롤·드래곤)을 ZA~ZE로 넣기 좋다.
- **단점**: 분류가 늘수록 규칙 줄이 늘어난다. AI가 첫 글자를 '의미'로 읽어 서술에 끌어올 위험이 약간 있다(이미지코드는 이미지 출력 이외에 쓰지 말라는 본문 줄이 막아 줌).
- 몬스터를 넣는다면 문안 — 34자(메인 +35자)
```
- 몬스터 공용: Z 접두(예: ZA=맹수). 상황코드 1만.
```
  - '상황코드 1만'은 몬스터 에셋이 '한 두 장'(일지)일 때를 가정했다. 실제 장수에 맞춰 바꿀 것.
  - 지금 상태창에 '[남성 인물/몬스터|…]' 줄이 있어 몬스터가 상태창에 들어갈 수는 있다. 몬스터 이미지 규칙은 아직 없다.

### 안 ④ 숫자 코드 (G01, G02…)

- **쓰지 말 것.** 상황코드가 숫자(1~83)라 AI가 이미지코드와 상황코드를 섞을 위험이 크다(예: `G12/5.webp`와 `G1/25.webp`).

## 4. 추천 — ①+② (+필요하면 ③의 몬스터 부분만)

- 기본 자리는 G A~Z → H A~Z로 이어 간다(안 ①). 지금 코드는 손대지 않는다.
- 이름 없는 단역은 GMOB/MMOB 공용(안 ②). 엑스트라·단역에 코드를 쓰지 않아 기본 자리가 거의 줄지 않는다. 이름이 붙은 최소 기능 인물(길드 접수원 등)은 기본 자리를 쓰되, 이름 없이 일반명사로 버틸 인물은 공용으로 돌린다(11-15 이름 우선순위와 같은 생각).
- 몬스터 에셋을 v1에 넣는다면 그때 Z 접두(안 ③의 일부).
- **마르타 GQ는 지금 배정해도 된다.** 에셋이 있고, 코드 칸이 '-'라서 지금은 마르타가 나와도 이미지가 생략된다. 표의 '-'를 'GQ'로 바꾸면 끝이다(에셋 폴더 이름을 GQ로 맞추는 것이 [출시]2의 조건).

## 5. 남성 코드

- 지금 남성은 MA(카일) 하나다. 제레미, 카미유(영주), 최소 기능 인물(남성 길드장 등)이 에셋을 얻으면 MB, MC…로 잇는다.
- 남성 인물은 일반 상황코드 1~25만 쓴다는 규칙은 그대로 적용된다. 카미유를 '!보추' 로어북으로 공략 대상으로 열 때 이 규칙과 부딪칠 수 있는 점은 A-10에서 다룬다.

## 6. 출시 전 확인과의 관계 ([출시]2·3)

- 표에 코드가 있으면 AI가 바로 출력한다. **업로드 전인 인물은 '-'로 두었다가 올린 뒤 바꾼다**([출시]2). GR·GS를 미리 적어 두지 말 것.
- 코드별 상황코드 범위가 다르면 규칙에 적는다([출시]3). 공용 코드(GMOB/MMOB)는 일반 상황 몇 장만 만들 가능성이 크니, 넣을 때 '1~25만' 같은 범위를 같이 적는 편이 안전하다.
