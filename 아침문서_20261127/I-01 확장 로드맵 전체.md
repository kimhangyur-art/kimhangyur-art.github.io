## 0. 원칙 (작가의 말에서)

- 출시부터 완벽하게 하지 않는다. 출시 뒤 활발히 업데이트한다(일지).
- 가드는 테스트에서(세션 정리 3절). 그러니 첫 업데이트는 거의 확실히 **테스트 피드백**이다.
- 동남쪽 안은 확장성(산맥·세계수)을 위한 선택이었다(11-26 밤).

## 2. 경로 셋 (순서 제안)

### 경로 ① — 여정을 따라가는 순서
U1 → U2 → **U4(헬무트)** → U5 → U3 → U6
- v1의 끝(국경)에서 이야기를 이어 간다. 유저가 가장 자연스럽게 받아들이는 순서.
- 단점: 동남쪽 안을 고른 이유(산맥·세계수)가 뒤로 밀린다.

### 경로 ② — 작가가 동남쪽 안을 고른 이유를 먼저
U1 → U2 → **U3(산맥·세계수)** → U4 → U5 → U6
- 착지 숲(동남쪽)에서 산맥 쪽으로 갈라지는 길을 연다. 일지·세션 정리의 확장 의도에 가장 가깝다.
- 단점: v1의 서쪽 여정이 끝나지 않은 채 동쪽으로 새 판이 열린다 — 두 갈래 진행을 AI가 감당해야 한다.

### 경로 ③ — 인물과 에셋 먼저
U1 → U2 → **U8(새 인물)** → U7 → 이후 ① 또는 ②
- 지형을 늘리지 않고 이미 있는 길 위에 사람을 늘린다. 에셋 작업이 병목이라면 가장 현실적.

## 3. v1에 '씨앗'으로 둘 것 / 두지 말 것

| 갈래 | v1에 씨앗을 둔다면 | 두지 말 것 |
|---|---|---|
| U3 | 착지 숲이 동남쪽이라는 사실 자체(이미 있음). 남동쪽 멀리 산맥이 보인다는 풍경 정도 | 세계수라는 이름(AI가 키움 — [대기15]의 권고) |
| U4 | 헬무트 첫인상(국경 너머). 법률상 마족 줄(이미 있음) | 헬무트 수도·마왕성의 이름 |
| U5 | 에반젤린 '관련된 듯'(이미 있음). 단편 '하나만 더'는 프롬프트 밖 | 가브리엘의 존재(작가: v1에는 넣지 말고) |
| U6 | 없음 | 북부에 대한 어떤 줄도 |
| U7 | 없음 | 200번대 코드 규칙 |
| U8 | 엑스트라 칸(A-09)이 몬무스를 받을 자리가 됨 | 몬무스 하나만 따로 |

**요점**: v1의 씨앗은 대부분 **이미 들어 있다**(동남쪽 착지, 법률상 마족, '관련된 듯'). 더 넣을 것은 거의 없다. 이것이 작가가 지금 v1을 '최소'로 잡은 것과 맞는다.

## 4. 갈래 사이의 맞물림

- **U3 ↔ 엘프**: 동대륙에 엘프가 많고(지리 줄), 중부 산맥은 소수만 통과한다. 세계수가 엘프와 이어진다면(제안), 엘프 모티브([대기7])의 결정이 U3보다 먼저 필요하다.
- **U4 ↔ 기사**: 헬무트 내부가 열리면 기사의 기억(의도적 공백)에 다가가는 장면이 생기기 쉽다. 작가가 그 조건을 정할 때까지 U4에서도 공백으로 둔다.
- **U5 ↔ 아니에스·마르타·에반젤린**: 교단 축. 가브리엘이 들어오면 아니에스의 신앙과 에반젤린의 저주가 한 줄기가 된다.
- **U8(드래곤) ↔ 메데이아 용인 폼**: 용족이 정식으로 등장하면 '용족 수준의 마법 능력'(로어북 12)의 기준이 생긴다.
- **U8(대족장) ↔ 아슬라·밀피**: 수인 연합 내부가 열린다. 밀피의 과거(무시받던 젖소 수인)와 아슬라의 '잊은 듯'이 마주친다 — '잊은 듯'을 확정하지 않도록 주의.

## 자기 대조

- 작가가 v1에서 뺀 것과 '나중에'를 일지·세션 정리 원문으로 근거를 댐.
- 의도적 공백(기사 기억 등)을 확장에서도 채우지 않음. '관련된 듯'·'실존은 증명되지 않음' 유지.
- 순서를 정하지 않고 경로 셋으로. 【신규】 없음.
