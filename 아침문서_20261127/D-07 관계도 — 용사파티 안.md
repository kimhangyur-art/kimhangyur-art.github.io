## 1. 누가 누구를 어떻게 보는가

|---|---|---|---|---|---|---|

**'본문 없음'이 많다.** 본문은 각 인물의 '카일을 향한 태도'와 한나의 실망에 집중한다. 파티원끼리의 관계(아니에스–리샤, 세라–아슬라 등)는 AI가 플레이에서 만든다. 그게 의도라면 이 표의 빈칸은 비워 둔 채로 좋다.

## 2. {{user}}를 보는 눈

교란마법: 계약자 한나를 제외한 모두에게 '평범하고 모날 것 없는 일반인=쓸만한 잡일꾼 사역마'로 인식됨(본문). 예외 없음.

| 인물 | 보는 것 |
|---|---|
| 한나 | 진짜를 앎. 부른 책임, 최대한의 배려, 기대 |
| 카일 | 쓸만한 잡일꾼. 화려한 여성진 속에서 신경 쓸 대상이 아님 |
| 아니에스 | 한나의 사역마 — 신앙의 틀에서 특별히 볼 이유가 없음 |
| 리샤 | 잡일꾼. 휘어잡을 가치가 없는 사람 — 그래서 리샤가 연기를 하지 않고 맨얼굴을 보일 수도 있는 상대(추정) |
| 세라 | 같은 일을 하는 사람(짐꾼과 잡일꾼). 가장 가까이서 일함 |
| 아슬라 | 약자 — 무관심 |

- 사람들은 '평범한 일반인' 앞에서 말을 고르지 않는다. 이 파티의 비밀 몇은 {{user}} 앞에서 가장 먼저 흘러나올 수 있다(리샤의 맨얼굴, 세라의 위화감 — A-01 ③).
- 인물들이 {{user}}를 부르는 호칭은 정하지 않는다.

## 3. 누가 무엇을 모르는가

| 비밀 | 아는 사람 | 모르는 사람 |
|---|---|---|
| 카일의 빙의(박민철) | 박민철 본인 | **파티 전원**(본문 '파티 내 누구도 모름') |
| 카일의 공격은 마왕의 재생을 못 뚫음 | 아무도(박민철 본인도 모름 — 본문) | 전원 |
| 기사의 정체(진짜 카일의 영혼) | 파티에는 없음 | 전원. 파티는 기사의 정체도 성별도 모름(그리팅 ②) |
| 리샤의 정기 블러핑·환각·처녀 | 리샤 | 카일(환각 속에서 믿음), 나머지 전원 |
| 리샤의 친모 맹신 | 리샤('누구에게도 밝힌 적 없음') | 전원 |
| {{user}}의 정체 | 한나 | 나머지 전원(교란마법) |
| 소환이 있었다는 것 | 한나 | 파티(한나가 정비하러 간 줄 앎 — 기억 범위) |
| 웹툰 ④⑤의 일(아슬라의 비꼼, 세라의 상처, 한나의 침묵) | 한나·세라·아슬라·아니에스 | 카일·리샤(기억 범위) |
| 한나의 속마음("이대로는 안 돼") | 한나 | 전원 |
| 세라의 검술 실력 | 세라, (카일의 몸 — 매일 대련했던 것은 진짜 카일) | 대부분(웹툰에서 싸우는 장면 없음). 박민철이 그 기억을 갖는지는 본문에 없음 |
| 세라–카일의 풋사랑 | 세라(그리고 진짜 카일) | 박민철은 '귀찮은 소꿉친구'로만 봄 |

**이 표가 보여 주는 것**: 파티의 모든 사람이 다른 누군가에 대해 **틀린 것을 믿는다.** 아니에스는 카일을 신의 사도로, 카일은 리샤와 관계 중이라고, 세라는 카일이 카일이라고, 아슬라는 카일을 강한 수컷 후보로, 파티 전원은 {{user}}를 잡일꾼으로. 한나만 진실 하나({{user}})를 쥐고 있고, 한나도 진실 셋(빙의·기사·리샤)을 모른다.

## 4. 관계가 바뀔 수 있는 고리 다섯

1. **세라의 검** — 세라가 처음으로 싸우는 순간. 아슬라의 평가(무관심 → 관심), 카일의 '도움도 안 되는'의 반박.
2. **커콜디의 리샤** — 리샤가 영주를 장악한 것을 파티가 보게 되면(B-03 4c), 카일은 리샤를 다시 보고, 한나는 리샤를 경계한다.
3. **한나의 '아직'의 끝** — 한나가 처음으로 파티 앞에서 카일을 거스르는 날. 아니에스가 가장 크게 반응할 것(사도님에 반하는 자 = '신의 뜻을 모르는 불쌍한 존재' — 본문).
4. **기사와의 재회** — 파티 전원이 정체를 모르는 상대. 세라만 무언가를 느낄 수 있다(A-01 ③). 기사의 기억은 다루지 않는다.
5. **네르구이** — 아슬라의 무관심이 함정이 되는 순간(A-06).

## 자기 대조

- 본문·웹툰·그리팅 근거와 추정을 칸마다 구분. 빈칸을 채우지 않고 '본문 없음'으로 둠.
- 빙의·기사·리샤의 비밀을 파티 누구도 모름 — 유지. 기사의 기억 회복은 다루지 않음.
- {{user}}는 남들 눈의 잡일꾼 사역마로만, 호칭 정하지 않음. 리샤의 비밀은 설정 수준으로만. 【신규】 없음.
