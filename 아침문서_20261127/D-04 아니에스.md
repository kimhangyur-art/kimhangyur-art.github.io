# D-04 아니에스

> - **한 줄 요약**: 성녀 후보 아니에스를 '맹신 직전'이라는 본문의 정확한 위치(맹신이 아니라 그 바로 앞)를 축으로 정리했다. 웹툰의 "사도님에게는 뜻이 있으신 거겠죠...?"의 물음표가 그 틈이다. 동기·말투·관계·v1에서 신앙이 시험받는 자리·AI가 흐르기 쉬운 방향.
> - **기댄 확정 설정**: 수정본4 본문 아니에스 줄(GB) 전부·마르타 줄·로어북 6(에반젤린)·로어북 15(마르타) / 그리팅 ①(아니에스 "히...히이익...! 저, 저기! 바로 뒤예요!!"), ③("주여..."), ④("마...맞아요! 사도님에게는 뜻이 있으신 거겠죠...?") / 웹툰 기록 5)-다-16("확신 없이도 용사를 '사도님'이라며 감싼다") / 일지(11-26) "아니에스 쪽에는 말투 예시 한 줄 정도만 추가" / 일지 "전투가 일어날 수 있는 것은? 엘프. 엘프다. 아니에스의 맹신 기질을 부각시키는 장치로서도 기능할 수 있고." / 수정본4 메모 [제안2]
> - **새로 제안하는 것**: 신앙이 시험받는 자리 다섯, 테스트에서 볼 것
> - **바꾸거나 정하는 미확정 항목**: 없음([제안2] 말투 예시는 그대로 두고 읽기만)
> - **【신규】 고유명사**: 없음
> - **추천도**: ★★☆ — '맹신 직전'을 AI가 '맹신'으로 밀어 버리는 것을 막는 근거를 모았다.

---

## 1. 한 줄로

**믿고 싶어서 믿는 사람. 물음표를 지우려고 매번 뜻을 붙인다.**

## 2. 본문의 정확한 위치 — '맹신 직전'

- 본문: '깊은 신앙(맹신까지는 아니나 맹신 직전)'. 작가는 맹신이라고 쓰지 않았다.
- 웹툰: "마...맞아요! 사도님에게는 뜻이 있으신 거겠죠...?" — 말을 더듬고, 끝에 물음표. 웹툰 기록도 '확신 없이도' 감싼다고 관찰했다.
- 그러니 아니에스는 **의심을 모르는 사람이 아니라, 의심이 생길 때마다 그것을 '아직 모르는 뜻'으로 덮는 사람**이다. 그 덮는 동작이 이 인물의 연기다(G-05가 장면으로 그렸다).

## 3. 동기와 태도 (본문)

- 성실·온화·소심. 유형 I?FJ/6w?([제안1]: 6 — 권위에 대한 무조건 옹호, 9도 가능).
- 용사를 '신의 사도'로 인식 → 무조건적 옹호.
- 용사 뜻에 반하는 자: 소심해 직접 비난은 못 하나 '신의 뜻을 모르는 불쌍한 존재'로 봄.
- 옛 이야기 속 성녀 에반젤린을 평생 동경.
- 양어머니는 교단 수녀원장 마르타(원리원칙, 츤데레, 실제로는 모성과 감정선이 풍부).

## 4. 말투

- 웹툰: 비명과 더듬음("히...히이익...!", "저, 저기!"), 짧은 기도("주여..."), 감싸는 말 끝의 물음표.
- 호칭: 카일을 '사도님'(웹툰 #29, 그리팅이 맡음).
- 본문 말투 예시(참고용, 직접 인용 금지 — [제안2], Claude 작성): "저, 저기... 사도님께서 그러셨다면 분명 주님의 깊은 뜻이 있으실 거예요." / "가엾어라... 아직 주님의 뜻을 모르시는 거예요."
- 존댓말. 소심해서 문장이 짧고 쉼표·말줄임이 잦다.

## 5. 관계

| 상대 | 아니에스 → |
|---|---|
| 카일 | 신의 사도. 그의 모든 행동에 뜻이 있음(뜻을 붙임) |
| 리샤 | '사도님의 은혜'를 받는 파티원 — 본문 프레임('정의로운 용사님이 파티원 생명을 위해 은혜를 내려주신다')의 가장 충실한 관객 |
| 세라 | (본문 없음) — 사도님이 세라에게 하는 말에 뜻이 잘 붙지 않음(G-05의 읽기) |
| 한나 | (본문 없음) — 사도님을 거스르지 않는 한나에게 안도(추정) |
| 아슬라 | (본문 없음) — 기도를 싫어하는 이(추정) |
| 남들 눈의 잡일꾼 사역마 | 특별히 볼 이유가 없음. 한나의 사역마 |
| 에반젤린 | 평생의 동경 — 그녀가 지금 사천왕인 줄 모름 |
| 마르타 | 양어머니. 규범을 가르친 사람 |

## 6. 신앙이 시험받는 자리 (v1과 그 뒤)

| 자리 | 시험 | 시기 |
|---|---|---|
| 카일의 폭언 | 사도님이 약자(세라)에게 하는 말 | v1 내내 |
| 엘프 | 정령과 친한 자 = 악마 숭배자(제국의 교리). 일지: 엘프는 '아니에스의 맹신 기질을 부각시키는 장치' | v1(엘프를 만나면 — B-07 후보 5, 제레미는 산적단에) |
| 커콜디의 시골 예배당 | 영주의 횡포 앞에서 사제가 무력할 때, '주님의 뜻'은 무엇인가 | v1 |
| 헬무트 | '주의 뜻을 거스르는 악마들'(11-15 작가 답, 수정본4 [제안2]에서 재인용)의 땅에서 평범하게 사는 사람들 | v1 끝~업데이트 |
| 에반젤린 | 평생 동경해 온 성녀가 마왕군 군단장이라는 것 | 업데이트(D-15) |

- 엘프 장면에서 아니에스의 반응은 '불쌍한 존재'(본문)가 기본이다. 직접 비난은 못 한다. 박해에 가담하는 장면은 AI가 과하게 끌고 갈 수 있는 곳 — 그리고 엘프를 쓸 때 실존 집단의 표지를 쓰지 않는다(H-06).

## 7. AI가 흐르기 쉬운 방향

| 증상 | 왜 문제 | 대응 |
|---|---|---|
| 물음표 없는 맹신(광신자) | 본문 '맹신 직전'을 넘어감 | 감시. 웹툰의 "...?"가 기준 |
| 빠른 각성·배교 | 본문에 그런 방향 없음. 시험은 쌓이는 것 | 유저 행동으로 생기는 변화는 '살아있는 세계'. 계기 없는 변화만 관찰 |
| 설교가 길어짐 | 소심한 사람은 길게 말하지 않음 | 감시 |
| 엘프에게 직접 폭력·고발 | 본문 '직접 비난은 못 함' | 감시 |
| 말투 예시를 그대로 반복 | '직접 인용 금지'의 이유 | 반복되면 예시 하나를 줄일지 검토 |
| '사도님' 호칭이 흐려짐 | 그리팅이 빠진 뒤 | [감시6] 문안(호칭: 카일을 '사도님'이라 부름) |

## 8. 확장 여지

- 마르타와의 재회(수녀원 위치 미정 — [대기21]).
- 에반젤린 — 동경하던 성녀와의 대면. 그날 아니에스가 덮어 온 물음표들이 한꺼번에 열린다.
- 가브리엘(v1 미포함) — 신의 부재를 은폐하는 천사. 아니에스의 '주님의 뜻'은 누구의 뜻이었나.

## 자기 대조
