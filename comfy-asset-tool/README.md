# 캐릭터 에셋 공방 (ComfyUI 보조 도구)

여러 캐릭터의 이미지 에셋 세트(표정, 상황 등)를 일관된 품질로 반복해서 만드는 보조 도구입니다.
이미지는 ComfyUI가 만들고, 이 도구는 준비 · 워크플로우 생성 · 결과 관리를 맡습니다.

## 실행

```bash
cd comfy-asset-tool
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest
npm run build    # dist/ 에 정적 파일 (상대 경로라 하위 폴더에서도 열림)
```

서버는 필요 없습니다. 프로젝트는 브라우저(localStorage)에 자동 저장되고, [프로젝트 저장]으로 JSON 파일로도 내려받을 수 있습니다.

## 작업 흐름

"줄" = 캐릭터 × 장면 하나. 줄마다 이미지 한 장을 만듭니다.

1. **준비** — [설정]에서 체크포인트 파일명을 정합니다(계열을 추정해 권장값이 들어갑니다). [캐릭터]에서 캐릭터를 만들고 [세트 적용]으로 표정 세트 같은 장면 묶음을 배정합니다. 의상·배경 같은 반복 문구는 [요소]의 조각으로, 단독 로라도 [요소]에서 만들어 장면에 배정합니다.
2. **초안 생성** — [생성]에서 "초안"으로 JSON을 저장해 ComfyUI에서 엽니다. 미정 줄만 들어 있고 시드는 실행마다 바뀝니다. 실행 버튼의 반복 횟수(Batch count)로 후보를 여러 장 뽑습니다.
3. **확정** — 마음에 드는 PNG를 도구 화면 아무 데나 끌어다 놓습니다. 파일 이름으로 줄을 찾고, PNG의 실행 정보에서 그 줄 KSampler의 시드를 읽어 고정한 뒤 "확정"으로 바꿉니다.
4. **반복** — 다시 초안을 만들면 확정된 줄은 빠지고 나머지만 뽑힙니다.
5. **마무리** — "마무리"로 JSON을 저장합니다. 확정 줄만, 고정 시드로, 고화질 단계를 덧붙여 다시 그립니다. 결과 PNG(파일 이름 끝에 `_final`)를 끌어다 놓으면 "완성"이 됩니다.
6. **내보내기** — [확정·내보내기]에서 완성 이미지를 `{캐릭터}/{장면코드}.png` 같은 이름 규칙으로 바꿔 zip으로 내려받습니다.

## ComfyUI 연결 (선택)

[설정 → ComfyUI 연결]에 주소(기본 `http://127.0.0.1:8188`)를 넣으면 `/object_info`에서 체크포인트·로라·샘플러·스케줄러·업스케일 모델 목록을 받아 드롭다운으로 보여 줍니다. 받아온 목록은 캐시해서 연결이 없을 때도 씁니다. 연결이 안 되면 직접 입력하면 됩니다.

브라우저에서 연결하려면 ComfyUI를 `--enable-cors-header` 옵션으로 실행해야 합니다.

## 설계 메모

- **프로젝트 파일이 원본**이고 워크플로우는 매번 새로 만드는 결과물입니다. ComfyUI에서 고친 내용은 돌아오지 않으니 수정은 도구에서 합니다.
- **설정 계층**: 프리셋(또는 내 프리셋) → 전역 → 그룹 → 장면. 화면에서 값마다 출처 배지를 보여 줍니다.
- **프리셋**은 `src/lib/presets.ts` 한 파일에 모여 있고, 값마다 출처를 주석으로 남겼습니다. v-pred 계열은 `ModelSamplingDiscrete`(v_prediction, zsnr)와 `RescaleCFG`를 넣습니다.
- **워크플로우 구조** (`src/lib/workflow/generate.ts`)
  - 기본 노드만 씁니다. 값은 각 노드에 직접 넣습니다. 예외는 구도 맞추기 그룹의 시드 공유(`PrimitiveInt`)뿐입니다.
  - 로라 조합별 `LoraLoader` 체인(앞부분이 같으면 공유), 체인마다 CLIP skip, (체인, 네거티브)마다 네거티브 인코딩, 해상도별 latent를 공유합니다. 로라가 없으면 체크포인트에서 바로 연결합니다.
  - 초안과 마무리는 기본 단계를 똑같이 만들고, 마무리는 기본 KSampler 뒤에 고화질 단계만 붙입니다. `workflow.test.ts`가 두 모드의 기본 단계가 같은지(ComfyUI가 받는 값 기준) 확인합니다.
  - 대상이 아닌 줄을 넣는 옵션을 켜면 `SaveImage`만 mute(모드 2)합니다.
  - 저장 경로는 `SaveImage`의 `filename_prefix`에 실제 경로로 들어가고, 파일 이름이 줄마다 고유하지 않으면 생성을 막습니다.
- `reference/hexmaniac_assets_workflow.json`은 ComfyUI JSON 형식(노드·links, 위젯을 입력으로 바꾼 연결 표기) 확인용 샘플입니다. 설정값·구조·배치는 따르지 않았고, 구조 검사기(`validate.ts`)가 이 샘플도 통과하는지만 테스트합니다.
- 완성 이미지 원본은 브라우저의 IndexedDB에 보관합니다. 다른 브라우저에서는 마무리 PNG를 다시 끌어다 놓아야 zip에 들어갑니다.

## 나중에 붙일 수 있게 열어 둔 곳

- **커스텀 노드 후처리**(FaceDetailer, 배경 제거 등): `generate.ts`의 `PostStage`. 마무리의 마지막 디코드와 저장 사이에 끼워지며, `requiredNodes`를 ComfyUI 연결로 받은 `nodeTypes`와 비교(`stageAvailable`)해 설치됐을 때만 켜면 됩니다. 노드 정의는 `nodeDefs.ts`에 더합니다.
- **한 이미지에 여러 캐릭터**: 줄 키가 `캐릭터|장면`이고 프롬프트 조합이 `composeRow` 한 곳에 모여 있어, 줄에 캐릭터 목록을 두는 식으로 넓힐 수 있습니다.
- **기준 이미지에서 표정만 바꾸기(img2img/인페인트)**: 기본 단계의 latent 입력(`EmptyLatentImage`)을 `VAEEncode`된 기준 이미지로 바꾸는 단계로 붙일 수 있습니다.
- **태그 자동완성**: 프롬프트 입력은 `src/ui/PromptEditor.tsx` 하나라 여기에 붙이면 됩니다.

## 폴더

```
src/lib/          데이터 구조, 프리셋, 설정 계층, 프롬프트 조합, 경로 규칙, PNG 읽기, 내보내기
src/lib/workflow/ 워크플로우 생성기, 노드 정의, 구조 검사, 실행 정보 변환
src/store/        Zustand 스토어(실행 취소/다시 실행, 자동 저장), 동작, 완성 이미지 보관(IndexedDB)
src/ui/           화면과 공통 부품
reference/        형식 확인용 샘플 워크플로우
```
